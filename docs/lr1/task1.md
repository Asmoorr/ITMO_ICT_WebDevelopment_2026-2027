# Задание 1. Обмен сообщениями по UDP

## Задача и реализация

Клиент отправляет строку `Hello, server`, сервер выводит её и отвечает `Hello, client`.
Обе стороны используют `socket.socket(socket.AF_INET, socket.SOCK_DGRAM)` — IPv4 и UDP.

Сервер привязывает сокет к `127.0.0.1:9001` через `bind()`. Вызов `recvfrom(1024)`
возвращает данные и адрес отправителя, который затем передаётся в `sendto()` для ответа.
Клиент не устанавливает TCP-соединение: адрес сервера указывается непосредственно при отправке.
Строки кодируются в UTF-8. Размер буфера — 1024 байта, клиент ждёт ответ не более 5 секунд.

## Запуск и пример работы

Терминал сервера:

```powershell
python Lr1/task1_udp/server.py
```

Терминал клиента:

```powershell
python Lr1/task1_udp/client.py
```

Вывод сервера при контрольном запуске:

```text
UDP-сервер запущен на 127.0.0.1:9001
Получено от ('127.0.0.1', 56160): Hello, server
Отправлено: Hello, client

```

Вывод клиента:

```text
Отправлено: Hello, server
Получено: Hello, client

```

Порт клиента назначает операционная система, поэтому он может отличаться.
После обмена сервер завершает работу. Для повторного запроса его нужно запустить снова.
При отсутствии ответа клиент выводит `Сервер не ответил вовремя`.
