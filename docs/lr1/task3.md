# Задание 3. Раздача HTML по HTTP

## Реализация

Сервер слушает `127.0.0.1:8080` через TCP-сокет. При запросе `GET / HTTP/1.1`
он читает `index.html` как байты и вручную формирует HTTP-ответ.
Путь к файлу вычисляется относительно `server.py` через `Path(__file__).with_name()`,
поэтому чтение HTML не зависит от текущей рабочей папки.

`build_response()` собирает строку статуса, заголовки, пустую строку `\r\n\r\n`
и тело. Для передачи используется `sendall()`.

| Запрос              | Ответ                                        |
|---------------------|----------------------------------------------|
| `GET /`             | `200 OK`, содержимое `index.html`            |
| Иной путь или метод | `404 Not Found`, текст «Страница не найдена» |

Это минимальная обработка первой строки запроса, а не полноценный HTTP-парсер.

## Запуск и проверка

```powershell
python Lr1/task3_http/server.py
```

Откройте `http://127.0.0.1:8080/` в браузере. Для проверки заголовков в другом терминале:

```powershell
curl.exe -i http://127.0.0.1:8080/
curl.exe -i http://127.0.0.1:8080/missing
```

Заголовки успешного ответа в проверенной версии:

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Content-Length: 971
Connection: close
```

`Content-Length` равен размеру HTML-файла в байтах; после изменения файла число изменится.
Контрольная проверка подтвердила совпадение тела ответа с файлом и код `404` для `/missing`.
