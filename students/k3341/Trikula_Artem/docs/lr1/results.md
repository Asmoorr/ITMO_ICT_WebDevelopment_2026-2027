## Выводы

UDP позволяет выполнить короткий обмен без установления соединения, но приложению
нужно самостоятельно учитывать отсутствие ответа. TCP предоставляет упорядоченный поток,
поэтому для прикладных сообщений необходимы явные границы и буферизация.

HTTP реализуется поверх TCP: заголовки определяют метаданные и размер тела,
а метод и путь задают действие сервера. Разделение разбора HTTP и обработки маршрутов
позволило вынести общую логику в `MyHTTPServer`.

В многопользовательском чате потоки позволяют параллельно обслуживать участников,
а блокировки защищают общий список клиентов и отправку кадров в один сокет.
В журнале словарь списков сохраняет связь дисциплины со всеми её оценками,
а запись через временный файл уменьшает риск повреждения JSON при замене данных.
