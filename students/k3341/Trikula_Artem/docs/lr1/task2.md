# Задание 2. Вычисления через TCP

## Задача и вариант

Клиент получает с клавиатуры длины двух катетов, сервер вычисляет гипотенузу:
c = √(a² + b²). Реализован вариант 1 для номера 33 в журнале.

## Формат обмена

Сервер использует `AF_INET`, `SOCK_STREAM`, адрес `127.0.0.1:9002`, `listen()` и `accept()`.
Клиент подключается через `socket.create_connection()` с тайм-аутом 5 секунд.
Запросы и ответы — JSON в UTF-8 с переводом строки в конце.

Запрос:

```json
{"a": 3.0, "b": 4.0}
```

Успешный ответ:

```json
{"ok": true, "hypotenuse": 5.0}
```

При отрицательном или нулевом катете:

```json
{"ok": false, "error": "Длины катетов должны быть положительными"}
```

`receive_all()` на сервере накапливает фрагменты до перевода строки или закрытия соединения.
`calculate_hypotenuse()` проверяет положительность катетов и выполняет вычисление.
Ошибки JSON, отсутствующие поля и некорректные типы перехватываются и возвращаются с `ok: false`.
После одного ответа соединение закрывается; сервер продолжает принимать новых клиентов последовательно.

## Запуск

```powershell
# Терминал 1
python Lr1/task2_tcp/server.py

# Терминал 2
python Lr1/task2_tcp/client.py
```

Введите `3` и `4`. В терминале получится:

```text
Катет a: 3
Катет b: 4
Гипотенуза: 5.0
```

При повторном запуске клиента с `-3` и `4`:

```text
Ошибка сервера: Длины катетов должны быть положительными
```

Оба результата подтверждены контрольным запуском настоящего клиента и сервера.
Нечисловой ввод отклоняется на клиенте при преобразовании в `float`.
